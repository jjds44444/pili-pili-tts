# Pili Pili — Tabletop Simulator mod

Unofficial fan implementation of the card game **Pili Pili** (Ben, Martin & JB /
ATM Gaming) for Tabletop Simulator. Python generates the card art and emits a TTS
save file; there is no runtime beyond TTS itself.

## Build

```bash
python build_save.py                    # render art + install into the TTS Saves folder
python build_save.py --out .            # write save + assets here instead
python build_save.py --skip-art         # reuse assets/, just rebuild the JSON
python build_save.py --base-url URL     # point images at a web host (multiplayer)
python validate.py <path>/PiliPili.json # structural check before loading in TTS
python preview.py preview.png           # contact sheet for eyeballing the art
```

Requires Python 3 and Pillow. Rendering all 106 card faces takes ~1 minute.

## Layout

| File | |
|---|---|
| `build_save.py` | Assembles the TTS save JSON. Entry point. |
| `art.py` | Draws every card face, back and token with Pillow. |
| `missions.json` | The 36 mission cards — data only, safe to edit. |
| `global.lua` | TTS table script: dealing, betting, Pilis, cleanup. |
| `validate.py` | Structural checks on a generated save. |
| `assets/` | Generated PNG sheets. Regenerated by `art.py`; not hand-edited. |

## Things that will bite you

**Deck sheets are grids.** A TTS `CustomDeck` is one image of `NumWidth × NumHeight`
card faces, and `CardID = deckId * 100 + indexOnSheet`. The play deck is 8×7 = 56
slots holding exactly 56 cards; missions are 6×6 = 36. Adding a mission past 36
overflows the sheet — bump the grid in `art.generate()` and the `custom_deck(...)`
call in `build_save.py` together, or cards silently render as the wrong face.

**The Lua finds objects by GMNotes, not GUID.** Decks get merged and re-created
constantly during play, so GUIDs are worthless. Every card and deck carries
`PILI:PLAY`, `PILI:MISSION` or `PILI:BID`, and `gather()` re-stamps the tag after
merging a pile back together. Keep that invariant or Deal/End Round stop finding things.

**Mission deal counts live in the card Description** as `[deal N]`, parsed by
`uiDeal()`. `build_save.py` appends it; don't strip it.

**Local `file:///` image paths only load for the table's host.** Everyone else sees
blank cards. Multiplayer needs `--base-url` pointing at publicly hosted copies of
`assets/`.

**Validate before loading.** TTS fails silently and unhelpfully on a malformed save —
a bad `CardID` gives you wrong card faces, not an error. `validate.py` catches the
common breakages.

## Two deliberate constraints

**All art is original.** Every pixel comes from `art.py`. Do not add scans, photos,
or exports of the published game's cards, and do not paste rulebook prose into card
faces or the notebook — mechanics aren't copyrightable, the publisher's artwork and
wording are.

**`missions.json` is a reconstruction.** The official rulebook (pp. 14–19) prints the
17 mission *effect types* but never the parameters of the 36 individual cards: how
many cards each deals, which way the pass arrows point, how many cards move, which
numbers are cursed. The current split covers all 17 effects plausibly. If someone
turns up with the physical deck, correcting `missions.json` and rebuilding is the
whole fix — don't restructure code for it.

## Not yet verified

The save has never been loaded in Tabletop Simulator. `validate.py` passes, but
in-game behaviour — hand zone placement, the XML panel layout, whether `deck.deal()`
and `gather()` behave as expected — is untested.
